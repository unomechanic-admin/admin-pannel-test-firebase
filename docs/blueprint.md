# **App Name**: UnoMechanic Admin Center

## Core Features:

- User Management: Comprehensive user data table, including viewing user details, searching, filtering, and the ability to ban users.
- Mechanic Management: Full mechanic data table. Mechanics may be verified, rejected, or suspended. Access mechanic-specific earnings reports.
- Booking Management: Complete bookings management tools: status updates, booking assignments, and cancellation functionality.
- Services Catalog Management: Service creation, updates, and deletion. Mark services as popular.
- Payment Processing: Track and manage payments. Refund capabilities included.
- Review Management: Access and moderate user reviews.
- Admin and Role Management: Manage administrators, including role-based access control (RBAC) management.
- Notifications Broadcast: Allows admins to send broadcast messages to all users.

## Style Guidelines:

- Primary color: Deep blue (#1A73E8), evoking trust, reliability, and authority suitable for an admin interface.
- Background color: Light gray (#F5F5F5), providing a clean and neutral backdrop for content display.
- Accent color: Bright cyan (#00BCD4), highlighting key interactive elements such as buttons and active states, ensuring an intuitive user experience.
- Body and headline font: 'Inter', a sans-serif font providing a modern, clean, and highly readable appearance for all text elements, is ideal for an admin dashboard. 
- Code font: 'Source Code Pro' for displaying code snippets.
- Use a consistent set of material-style icons to visually represent different functions and data categories within the dashboard. Adopt a filled style with the primary color for active states and outlined for inactive states.
- Implement a sidebar navigation for primary sections and a top bar for user-specific actions, adhering to a clear hierarchical structure. Employ a grid-based layout for responsive content arrangement, and cards to logically group related elements. Maintain balanced spacing and margins for optimal visual ergonomics.
- Use subtle transition animations to create a fluid and engaging user experience. Animate table row expansions, modal appearances, and navigation transitions to enhance visual appeal without detracting from task focus.
